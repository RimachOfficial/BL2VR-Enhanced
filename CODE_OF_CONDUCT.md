# Code of Conduct

## Our pledge

We want this project to be a friendly place to learn VR modding, reverse-engineering basics, and
C++. Everyone who participates is expected to help make that true.

## Expected behaviour

- Be respectful and patient, especially with newcomers.
- Argue ideas, not people. Technical disagreement is welcome; hostility is not.
- No harassment, discrimination, gatekeeping, or bad-faith trolling.
- Keep discussion on-topic for the project (this repo's issues/PRs).

## Enforcement

Unacceptable behaviour can be reported privately to the maintainers via GitHub
(see [SECURITY.md](SECURITY.md) for private reporting channels). Maintainers may
warn, moderate, or ban participants at their discretion; all decisions are final
for this project.

## Scope

This code of conduct applies to all project spaces: issues, pull requests, discussions,
and any community channels the project may open.
