How to apply (from the BL2VR-grip project):
  1. Copy src\filters.h and src\ovrhook.cpp over openvr_proxy\src\ (originals are in git; only ~40 lines changed).
  2. Rebuild openvr_api.dll with your normal build.bat, install it.
  3. Copy bl2vr_grip.ini over the one next to the DLL in the game folder (hot-reloads every 2 s).
  4. Hold ONLY the gun-hand trigger for a few seconds, release it, then open openvr_proxy.log (next to the DLL) and send/read the line(s):
        trigger gate -> HELD ...   /   trigger gate -> released ...
     If there is no such line, or trig=0.000 or poll_rc is not 0, the trigger is not being read (that is the "no smoothing on trigger" bug).
  Optional offline check (no game needed):  g++ -O2 -std=c++17 filter_bench.cpp -o filter_bench && ./filter_bench

NOT compiled against the game here (no MSVC in this environment). filters.h IS compiled and tested offline.
catchup_pos=0 and catchup_rot=0 give exactly the old behaviour.
